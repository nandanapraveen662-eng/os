This is an interactive FCFS (First-Come, First-Served) CPU scheduling visualiser, a single HTML file (`fcfs_visualiser.html`) that opens in any browser, plus a Word report (`FCFS_Scheduling_Report.docx`) analysing two activities. Processes run in arrival order and keep the CPU until they finish, with a context-switch cost of 0 ms in Activity 1 and 1 ms in Activity 2. You can edit arrival and burst times and watch the Gantt chart, ready queue and results update, stepping through the schedule one millisecond at a time. It reports completion, turnaround, waiting and response times and CPU efficiency. With the default data, Activity 1 finishes in 14 ms with an average waiting time of 4.75 ms, and Activity 2 finishes in 17 ms with 6.5 ms and 82.35% efficiency.
